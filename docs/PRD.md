# PRD｜enterprise-rag-gateway 私有化企业RAG网关

## 1. 产品定位
面向政企、央企私有化知识库交付，在问答能力之外补齐**多租户、文档细粒度权限、审计、敏感过滤、增量同步**，
解决普通 RAG Demo「缺少合规能力、无法进内网投产」的痛点。核心设计原则：**先控权限，再做问答**。

## 2. 用户角色
- 交付 FDE：部署私有化知识库、对接客户 OA / 文件中心
- 客户运维：管理租户、文档权限、查看审计日志
- 内部员工：在权限范围内查询内部知识库
- 安全审计：追溯查询行为、敏感内容访问记录

## 3. 用户故事
1. 作为运维，我需要新建租户，不同租户向量空间隔离，数据互不干扰。
2. 作为管理员，我需要给文档绑定组织/角色白名单，只有有权限的人才能检索该文档片段。
3. 作为交付，我需要对接客户文件中心，增量同步文档，兜底全量对账，避免文档丢失。
4. 作为安全岗，我需要全链路审计日志：谁、什么时间、问了什么、检索了哪些文档、返回结果。
5. 作为使用者，我提问时自动过滤无权限文档，不会返回越权内容。

## 4. 核心功能清单
1. 多租户管理，租户独立向量空间隔离。
2. 文档级权限标签：组织、角色白名单映射。
3. 文档 Ingestion：解析、分块、向量化；增量同步 + 全量对账兜底。
4. 检索链路：向量召回 + Rerank（可开关），**召回阶段权限过滤**。
5. 身份鉴权：对接外部 IAM / 身份系统同步的用户角色与组织。
6. 敏感词过滤、回答水印、导出管控。
7. Prompt 模板管理（可租户独立配置问答 Prompt）。
8. 全链路审计日志，支持检索导出。
9. Docker 一键离线部署。

## 5. 非功能需求
1. 数据不出域，向量库、文档、日志全部内网存储。
2. 兼容 LiteLLM/OneAPI，任意后端 LLM（可选）。
3. 目标容量：十万级文档以内企业知识库。
4. 日志不可篡改，满足等保审计溯源要求。
5. 低算力模式可关闭重排，降低资源消耗。

## 6. 验收标准（v0.1，本仓库当前）
1. `docker compose up -d` 或 `make run` 可启动；`make demo` 可跑全链路。
2. 租户创建、文档权限标签配置生效，越权用户检索不到受限文档（`make test` 全绿）。
3. 问答链路正常，审计日志落库。
4. 样例语料同步脚本（`sync_corpus` / `POST /sync`）可运行，支持增量 + 全量对账。

## 7. 迭代路线
- v0.1：租户、文档权限、审计、基础问答（当前）
- v0.2：OA / 文件中心适配器、增量同步
- v0.3：溯源引用、水印、导出管控
- v0.4：对接 enterprise-ai-eval-harness 自动评测 RAG 效果
