# Limitation 局限说明（README 同步引用，面试重点）

1. **本项目不提供完整 IAM 身份系统**，只做权限标签映射，依赖外部身份源（OA / IAM）同步角色与组织。
2. **不支持亿级超大文档库**，适合企业内部制度、安全文档、项目资料知识库（十万级以内）。
3. **重排模型消耗算力**，低配置服务器建议关闭 rerank（`RERANK=false`）。
4. **敏感词过滤是内置规则库**，无法覆盖全部行业黑词，需要客户自行补充行业词表。
5. **不做文档在线预览**，只做检索问答。
6. **确定性哈希向量**（POC 零依赖）语义能力有限，生产应替换为真实向量模型（接口不变）；多轮上下文能力依赖底层 LLM。
7. 向量检索为**内存实现**（POC 量级），生产应接入 pgvector / 专用向量库做持久化与索引。
8. 面向内部知识库 / POC 验证，未做超大并发、分布式设计。
